# ЯЖЕМОХ

Интерактивная мастерская с 3D-сценой, карточками экспонатов и галереями материалов.

## Разработка

Требуется Node.js 18 или новее.

```sh
npm --prefix frontend/react ci
npm --prefix frontend/react run dev
```

Vite напечатает адрес сайта. Комната и карточки работают на одной странице.

## Локальный предпросмотр сборки

```sh
npm --prefix frontend/react run build
python3 backend/serve.py --port 0 --open
```

Сборка находится в `frontend/react/dist/`. Python 3.7 или новее нужен только для локальной раздачи файлов. Скрипт `run-local.bat` использует комплектный Python для Windows x64. Для офлайн-архива приложите папку сборки вместе с `backend/`, `runtime/` и `run-local.bat`. Адрес предпросмотра появится в терминале. Остановить сервер можно клавишами Ctrl+C.

## Структура

- `frontend/react/index.html` — разметка рабочей комнаты и подключение приложения.
- `frontend/react/src/workshop/` — сцена Three.js, управление камерой, каталог, навигация и просмотр моделей.
- `frontend/react/src/ExhibitDialog.jsx` — карточки, галерея, параметры этажерки и научные подразделы.
- `frontend/react/public/` — фотографии, документы, модели, шрифты и фон сцены.
- `backend/serve.py` — локальный сервер готовой сборки.

Каталог и навигация общие для предметов сцены, меню и карточек. Чтобы открыть карточку напрямую, используйте адрес с фрагментом, например `/#firefly`. Для работы моделей и загрузки локальных документов открывайте сайт через Vite или Python-сервер.
