# ЯЖЕМОХ — локальная версия сайта

Интерактивная мастерская с 3D-моделями и галереей материалов.

## Архитектура проекта

```text
YAZHEMOH-review/
├── frontend/              # Всё, что загружается в браузер
│   └── dist/              # Готовая версия сайта: HTML, CSS, JS, изображения и модели
│   └── react/             # React/Vite-каркас для постепенной миграции
├── backend/               # Локальный сервер для предпросмотра
│   └── serve.py           # Python-сервер и MIME-типы для моделей и файлов
├── runtime/               # Переносимый Python для Windows
├── run-local.bat          # Быстрый запуск на Windows
└── START-HERE.txt         # Краткая инструкция для получателя архива
```

В этой версии отдельного API-сервера нет: `backend/serve.py` только раздаёт готовые файлы из `frontend/dist/` и должен запускаться локально. Для редактирования интерфейса используйте файлы в `frontend/dist/`.

## Быстрый запуск

### macOS или Linux

Требуется Python 3.7 или новее.

Из корня проекта выполните:

```bash
python3 backend/serve.py --port 0 --open
```

Сервер напечатает адрес вида `http://127.0.0.1:XXXXX/`. Оставьте терминал открытым во время проверки сайта.

Для остановки нажмите `Ctrl+C`.

### Windows

Самый простой способ — дважды щёлкнуть `run-local.bat`. Сайт откроется в браузере автоматически.

Также можно запустить из терминала:

```bat
runtime\python\python.exe backend\serve.py --port 0 --open
```

Если установлена обычная версия Python:

```bat
py -3 backend\serve.py --port 0 --open
```

или:

```bat
python backend\serve.py --port 0 --open
```

Оставьте окно сервера открытым, пока проверяете сайт.

## React-промежуточная версия

Существующий JavaScript-интерфейс сохранён в `frontend/dist/` и остаётся основным рабочим fallback.

Для запуска React-каркаса:

```bash
cd frontend/react
npm install
npm run dev
```

React откроет мастерскую по адресу `http://127.0.0.1:5173/`. Dev-сервер отдаёт legacy-файлы с корректными MIME-типами для `.gz`, JS и 3D-моделей.

Для запуска legacy-версии отдельно:

```bash
cd ../.. && python3 backend/serve.py --port 0 --open
```

Для production-сборки React-каркаса:

```bash
cd frontend/react
npm run build
```

Сборка сохраняется в `frontend/react/dist/`. На этом этапе React показывает существующую мастерскую через полноэкранную обёртку, поэтому переход не изменяет и не удаляет исходную реализацию.

## Важные правила

- Не открывайте `frontend/dist/index.html` двойным щелчком: для корректной загрузки модулей и 3D-моделей нужен локальный сервер.
- Не перемещайте папки `frontend/dist/` отдельно от проекта без обновления настроек сервера.
- Для внешних ссылок на MakerWorld, журналы и Telegram требуется интернет. Самой мастерской интернет не нужен.
