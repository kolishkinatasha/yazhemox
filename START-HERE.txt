ЯЖЕМОХ · локальная версия сайта для проверки
23 ноября 2026

Windows 10/11, x64
1. Нажмите «Извлечь всё» и распакуйте ZIP целиком.
2. В распакованной папке YAZHEMOH-review запустите run-local.bat.
   Мастерская откроется в браузере. Если вкладка не открылась автоматически,
   скопируйте адрес из строки Local: в окне сервера.
3. Оставьте это окно открытым, пока проверяете сайт. Закройте его для остановки.

Подойдёт современный Chrome, Edge, Firefox или Safari. Сама мастерская,
3D-модели, фотографии и локальные PDF доступны без интернета. Для переходов
на MakerWorld, сайты журналов и в Telegram понадобится интернет.

macOS и Linux
С установленным Python 3.7 или новее откройте терминал в распакованной
папке YAZHEMOH-review и выполните:
    python3 backend/serve.py --port 0 --open
Если вкладка не открылась, используйте адрес из строки Local:. Подробности
и описание структуры проекта находятся в README.md.

Windows на другой архитектуре
С установленным Python 3.7 или новее откройте терминал в распакованной
папке YAZHEMOH-review и выполните:
    py -3 backend/serve.py --port 0 --open
Если у вас доступна команда python, можно использовать её вместо py -3.

Для открытия сайта нужен локальный сервер. Если открыть frontend/dist/index.html
как обычный файл, браузер не загрузит часть компонентов и моделей.

В runtime/python/ лежит официальный переносимый Python 3.14.10 для Windows x64.
